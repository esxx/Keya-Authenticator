Politique de confidentialité

Date d'entrée en vigueur : 1er mai 2026
En bref : Keya Authenticator ne collecte aucune donnée personnelle. Rien de ce que vous saisissez ou générez ne quitte jamais votre appareil.

1. Aucune collecte de données

Keya Authenticator ne collecte, ne transmet, ne stocke ni ne partage aucune information personnelle. L'application n'a aucune autorisation réseau et ne peut pas se connecter à Internet.

2. Ce qui reste sur votre appareil

Les données suivantes sont stockées uniquement en local sur votre appareil :

  • Secrets 2FA — stockés dans le trousseau iOS avec kSecAttrAccessibleWhenUnlockedThisDeviceOnly. Ils ne peuvent pas être lus lorsque l'écran est verrouillé et ne sont pas inclus dans les sauvegardes iCloud ou iTunes.
  • Réglages de l'application — stockés dans UserDefaults (thème, ordre de tri, préférences de verrouillage). Ne contient aucun secret.
  • Hachage du code PIN — stocké dans le trousseau à l'aide de PBKDF2-HMAC-SHA256 avec 100 000 itérations. Votre code PIN n'est jamais stocké en clair.

3. Aucun SDK tiers

Keya Authenticator ne contient aucun SDK d'analyse, de publicité, de rapport de pannes ou tout autre SDK tiers. Les seuls frameworks système utilisés sont ceux fournis par Apple (CryptoKit, LocalAuthentication, Security, StoreKit).

4. Achats intégrés

Le système de pourboires optionnel utilise le framework StoreKit d'Apple. Les achats sont traités entièrement par Apple. Keya Authenticator ne reçoit aucune information de paiement ni aucune donnée personnellement identifiable suite à un pourboire.

5. Caméra et photothèque

L'accès à la caméra n'est demandé que lorsque vous choisissez de scanner un QR code. L'accès à la photothèque n'est demandé que lorsque vous choisissez d'importer un QR code depuis une image enregistrée. Ni le flux caméra ni les images ne sont stockés ou transmis.

6. Face ID / Touch ID

L'authentification biométrique est gérée entièrement par iOS. Keya Authenticator n'a jamais accès à vos données biométriques. Il reçoit uniquement un résultat booléen succès/échec du système d'exploitation.

7. Code ouvert

Keya Authenticator est entièrement open source sous la licence GPL v3. Toute personne peut auditer le code source complet pour vérifier ces affirmations.

8. Confidentialité des enfants

Keya Authenticator ne collecte aucune donnée de qui que ce soit, y compris les enfants de moins de 13 ans. Il n'y a rien à collecter.

9. Modifications de cette politique

Si cette politique change, la version mise à jour sera publiée à cette URL avec une nouvelle date d'entrée en vigueur. Étant donné qu'aucune donnée n'est collectée, des modifications importantes sont peu probables.

10. Contact

Des questions sur cette politique ? Ouvrez un ticket sur GitHub ou envoyez un e-mail à KeyaAuthenticator@exx.ee.
