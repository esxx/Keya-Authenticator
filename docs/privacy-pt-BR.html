Política de Privacidade

Data de vigência: 1º de maio de 2026
Resumo: O Keya Authenticator não coleta nenhum dado pessoal. Nada que você insira ou gere jamais sai do seu dispositivo.

1. Nenhuma Coleta de Dados

O Keya Authenticator não coleta, transmite, armazena nem compartilha nenhuma informação pessoal. O aplicativo não possui permissões de rede e não consegue se conectar à internet.

2. O Que Fica no Seu Dispositivo

Os seguintes dados são armazenados apenas localmente no seu dispositivo:

  • Segredos 2FA — armazenados no Keychain do iOS com kSecAttrAccessibleWhenUnlockedThisDeviceOnly. Não podem ser lidos com a tela bloqueada e não são incluídos nos backups do iCloud ou iTunes.
  • Configurações do app — armazenadas no UserDefaults (tema, ordem de classificação, preferências de bloqueio). Não contém segredos.
  • Hash do PIN — armazenado no Keychain usando PBKDF2-HMAC-SHA256 com 100.000 iterações. Seu PIN nunca é armazenado em texto simples.

3. Nenhum SDK de Terceiros

O Keya Authenticator não contém análises, publicidade, relatórios de falhas nem qualquer outro SDK de terceiros. Os únicos frameworks do sistema utilizados são os fornecidos pela Apple (CryptoKit, LocalAuthentication, Security, StoreKit).

4. Compras no App

O cofre de gorjetas opcional usa o framework StoreKit da Apple. As compras são processadas inteiramente pela Apple. O Keya Authenticator não recebe dados de pagamento nem informações de identificação pessoal como resultado de uma gorjeta.

5. Câmera e Fototeca

O acesso à câmera é solicitado apenas quando você opta por escanear um QR code. O acesso à fototeca é solicitado apenas quando você opta por importar um QR code de uma imagem salva. Nem o feed da câmera nem as imagens são armazenados ou transmitidos.

6. Face ID / Touch ID

A autenticação biométrica é tratada inteiramente pelo iOS. O Keya Authenticator nunca tem acesso aos seus dados biométricos. Ele recebe apenas um resultado booleano de sucesso/falha do sistema operacional.

7. Código Aberto

O Keya Authenticator é totalmente de código aberto sob a licença GPL v3. Qualquer pessoa pode auditar o código-fonte completo para verificar essas afirmações.

8. Privacidade de Crianças

O Keya Authenticator não coleta nenhum dado de ninguém, incluindo crianças menores de 13 anos. Não há nada para coletar.

9. Alterações nesta Política

Se esta política mudar, a versão atualizada será publicada neste URL com uma nova data de vigência. Como nenhum dado é coletado, mudanças materiais são improváveis.

10. Contato

Dúvidas sobre esta política? Abra uma issue no GitHub ou envie um e-mail para KeyaAuthenticator@exx.ee.
